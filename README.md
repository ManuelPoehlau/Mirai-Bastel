# Mirai-Bastel

Ein experimenteller 3D-Modeler, inspiriert vom direkten Modeling-Workflow von Mirai, Silo und Wings3D.

## Vision

Ein kleiner, schneller und intuitiver Polygon-/Subdivision-Modeler: wenig UI, direkte Maus-/Tastaturinteraktion, Hover und Tweak statt Tool-Overhead. Die langfristige Idee ist ein Modeler, dessen Mesh auch nach Rigging, Morphs und Animation weiterbearbeitbar bleibt.

## V1-Ziel

Modeling ungefähr wie Silo/Wings3D, ergänzt um die besonders interessanten Workflow-Ideen aus Mirai.

Der erste Schwerpunkt liegt auf:

- Vertex / Edge / Face / Object
- Selection und Hover
- Translate / Rotate / Scale
- Tweak
- Soft Selection
- Perspective / Orthographic und Standardansichten
- grundlegende Modeling-Operationen
- saubere Topologie- und Mesh-Datenstrukturen
