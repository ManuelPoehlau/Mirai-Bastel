# Mirai

3d Modelling- Animation Software in the Spirit of the old Izworld/Nichimen Software. Inspired by old works of Bay Raitt,
Martin Krol and the Weta Digital Crew works on Gollum.

## Vision (what it should be)

- Lightweight Modeller
- Intuitive, Context based Interaction Workflow
- Minimal UI
- Easy to switch between Modelling/Deformation/Morphing/Rigging/Skinning/Animation
- Easy to understand. Context based interaction options always visible to the User
- Fun to Use
- It should **not** just copy other DCC´s tools, creative and unconventional Tools/Methods are allowed.
- It´s taylored to Manus worklflow ideas and we´re not worrying about the publics needs when it comes to UI/Workflows.
