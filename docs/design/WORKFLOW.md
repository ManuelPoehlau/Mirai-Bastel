# Workflow Principles

## Guiding idea

**See → Hover → Grab → Move.**

The user should be able to work directly with visible geometry whenever possible.

## Core principles

1. Few, memorable modes.
2. Mouse position and hover provide context.
3. Keyboard modifiers may refine an operation where useful.
4. Tweak should allow direct manipulation without an additional tool step.
5. Camera and modeling should remain fast and reliable to operate.
6. Keep UI noise low.
7. Consider Undo/Redo from the beginning.

## Inspiration

V1 is practically inspired by Silo/Wings3D while also investigating historical Mirai/Weta workflows. Historical details are not treated as established facts unless supported by a source or reproducible observation.

## Relationship to experiments

These principles describe desired interaction behavior, not fixed shortcuts or implementation structure. Viewport and topology experiments are expected to challenge and refine them through practical use.

When an experiment produces a lasting workflow decision, update this document or the appropriate design/future-idea document instead of creating a second permanent copy in the experiment.
