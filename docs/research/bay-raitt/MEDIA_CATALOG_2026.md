## Bay Raitt — primary portfolio source

https://spiraloid.artstation.com/projects/o693m

Raitt describes himself as Creature Facial Lead for all three Lord of the Rings films and describes the facial system as a combinatoric network of roughly a thousand shapes built with Mirai and Larry Malone.

Research value:

- first-person production context
- direct connection between Mirai and Gollum facial work
- evidence that the Mirai/Weta workflow extended far beyond ordinary polygon modeling

## What to extract from the videos

Do not only archive the finished model. For each useful video, record:

1. Selection mechanism
2. Hover behavior
3. Mouse-button semantics
4. Modifier keys
5. Camera switching
6. Transform initiation
7. Tweak behavior
8. Soft-selection/falloff behavior
9. Topology operations
10. Undo/redo behavior if visible
11. Whether the artist changes modes or stays in one continuous interaction state
12. Any evidence of animation/rig/deformation surviving continued modeling

The last point is especially important for our long-term project vision.

## Historical significance

Bay Raitt's videos are valuable because they demonstrate **behavior**, which static screenshots and feature lists cannot capture.

For the Mirai-Bastel project, the videos should therefore be treated almost like experimental recordings of a user interface: observe the sequence of actions, infer the underlying interaction contract, then compare those observations with contemporary documentation.

## Separation of evidence

When cataloging a behavior, label it as one of:

- `OBSERVED` — directly visible in a surviving video/image
- `DOCUMENTED` — stated in a manual/article/contemporary source
- `INFERRED` — plausible explanation based on multiple observations
- `UNKNOWN` — not enough evidence yet

Never turn an inference into a documented fact merely because it fits how Mirai appears to work.
