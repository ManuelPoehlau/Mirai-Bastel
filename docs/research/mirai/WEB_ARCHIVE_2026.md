# Mirai — Web Archive / Rediscoveries (2026)

> Research snapshot: 2026-08-25
>
> Purpose: preserve discoveries that are useful for understanding Mirai itself, not merely collecting nostalgia material.

## 1. Dedicated historical information site

**Symbolics S-Graphics / Nichimen N-World / Izware Mirai information site**

https://s-graphics.neocities.org/

This is currently one of the most valuable surviving hubs. It documents the lineage from Symbolics S-Graphics → Nichimen N-World → Mirai and points to surviving videos, N-World 3.0 documentation and Wayback Machine captures of historical company sites.

Important because it connects Mirai to the older S-Graphics/N-World system instead of treating Mirai as an isolated 1990s modeler.

## 3. Contemporary technical/product information

### Game Developer Magazine — April 2000

https://ubm-twvideo01.s3.amazonaws.com/o1/vault/GD_Mag_Archives/GDM_April_2000.pdf

Contemporary product coverage of Mirai 1.1. Particularly valuable because it describes features at the time rather than reconstructing them decades later.

Notable points reported in the article include:

- Mirai 1.1 as the evolution of the package that replaced N-World as Nichimen's flagship.
- render/display/I/O improvements
- Game Exchange 2.1 support
- improved OBJ/3DS export
- additional modeling options
- improved camera manipulation
- magnet movement of multiple vertices with falloff
- skeletal animation improvements including magnet operations, squash/stretch and root rotation

This is exactly the kind of contemporary evidence we should prioritize in the archaeology.

## 4. Mirai interaction evidence

### Game Developer Magazine — December 1999

https://valvearchive.com/archive/Other%20Files/Publications/The%20Cabal%20%28Ken%20Birdwell%29/The%20Cabal%20%28Valve%27s%20Design%20Process%20For%20Creating%20Half-Life%29/Game%20Developer%20Magazine/GDM_December_1999.pdf

Contains a contemporary description of Mirai's interaction philosophy. Especially important for our project because it describes selection/context-driven interaction, camera mode switching and the use of left/middle/right mouse buttons with context-dependent results.

This is strong evidence that the unusual workflow we remember was not merely a consequence of Bay Raitt's personal technique: the interaction model itself was a deliberate product characteristic.

## 5. Bay Raitt / Gollum primary-ish source

Bay Raitt's current ArtStation page:

https://spiraloid.artstation.com/projects/o693m

Raitt describes his role as Creature Facial Lead for the Lord of the Rings trilogy and states that he built a large combinatoric facial-shape network using Mirai together with Larry Malone.

This is valuable for understanding the later production use of Mirai, while remembering that Weta's production environment was necessarily more than the public Mirai product.

## 7. Community rediscoveries after the original Mirai era

A 2006 Blender Artists thread shows that Mirai was already difficult to obtain shortly after Izware's decline and that Wings3D was explicitly regarded as a Mirai/Nendo-inspired successor.

https://blenderartists.org/t/mirai/352993

A 2026 XPForums thread unexpectedly contains a large collection of old Mirai images/GIFs and references to Bay Raitt and Martin Krol videos. This is a useful rediscovery lead, but community-hosted material should be treated as secondary evidence and archived carefully rather than assumed authoritative.

https://www.xpforums.com/threads/the-official-nichimen-mirai-thread-nendo-too.935716/

## 8. Research priority

For future archaeology, prefer sources in this order:

1. Original manuals / online documentation
2. Contemporary Nichimen/Izware material
3. Contemporary trade magazines
4. Statements or portfolios by original developers/artists
5. Wayback Machine captures
6. Surviving software and its bundled documentation
7. Community archives / forum posts
8. Modern summaries / Wikipedia-style sources

## 9. Important observation

The surviving material is much richer than it initially appears, but it is fragmented. The most promising path is therefore not to search only for "Mirai". Search the entire lineage:

```text
Symbolics S-Graphics
        ↓
S-Geometry / S-Paint / S-Dynamics / S-Render
        ↓
Nichimen N-World
        ↓
Mirai
        ↓
Nendo
        ↓
Wings3D
```

That lineage is likely to reveal architectural and workflow information that is missing from Mirai-specific pages.
