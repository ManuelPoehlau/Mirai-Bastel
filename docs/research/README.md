- `weta/` – Weta Digital, LOTR/Gollum und maßgeschneiderte Systeme

- `subdivision/` – Catmull-Clark und verwandte Verfahren

- `deformation/` – Skinning, Morphs, nicht-destruktive Deformation

Jede Quelle sollte möglichst mit URL, Datum, Quelle/Autor und einer kurzen Einordnung dokumentiert werden.
