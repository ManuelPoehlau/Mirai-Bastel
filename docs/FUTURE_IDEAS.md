# Mirai-Bastel – Future Ideas

Dieses Dokument ist das langfristige Projektgedächtnis für Ideen, Wünsche
und Beobachtungen, die bewusst **noch nicht umgesetzt** werden sollen.

Es ist ausdrücklich kein kurzfristiges TODO. Ein Eintrag bedeutet:
> Im Hinterkopf behalten – später erneut bewerten.

Wenn aus einer Idee ein konkretes nächstes Vorhaben wird, kann sie in eine
Roadmap oder ein passendes TODO-Dokument überführt werden.

---

## Viewport / Navigation

### Freier Orbit

Die aktuelle V1-Kamera begrenzt den vertikalen Orbit auf ±85°.

Später prüfen, ob zusätzlich ein vollständig freier Orbit wie aus
3ds Max oder ZBrush angeboten werden soll. Die aktuelle Begrenzung bleibt
für V1 bewusst bestehen.

### Alternative Navigationskonventionen

Später eventuell mehrere Navigationskonventionen bzw. einstellbare
Navigation anbieten. Unterschiedliche 3D-Anwendungen verwenden teilweise
unterschiedliche Orbit-/Drag-Konventionen.

### Viewport View Snapping

Inspiration aus ZBrush: eine Modifikatortaste (z. B. Shift) könnte während
des Orbit-Drags zur nächstgelegenen Standardansicht snappen.

Mögliche Ziele:

- Front
- Back
- Left
- Right
- Top
- Bottom

Details und konkrete Bedienung erst bei der späteren Beschäftigung mit
der Navigation festlegen.

### Orbit / Zoom Focus

Später eventuell Navigation relativ zu Objekt oder Auswahl anbieten:

- Orbit around Object
- Orbit around Selection
- Zoom to Object
- Zoom to Selection

V1 bleibt bewusst beim Scene-Zentrum als Orbit-/Zoom-Zentrum.
